# 광산 생활배출 길잡이

광산구 시민을 위한 모바일 중심 생활폐기물 안내 웹앱입니다. `dist/`가 바로 배포 가능한 정적 사이트입니다.

## 기능

- 휴대폰 카메라·앨범 사진을 브라우저에서 MobileNet으로 분석해 비슷한 품목 제안
- 10개 복합 품목의 재질·상태별 분리 단계, 전처리, 주의사항
- 동·지역별 생활쓰레기, 음식물쓰레기, 재활용품의 정기 배출요일과 오늘·다음 배출일
- 공개 판매소 일부의 주소, 위치 검색, 거리순 목록, 지도, 길찾기

## 데이터와 한계

- 사진 분류는 [TensorFlow.js MobileNet](https://github.com/tensorflow/tfjs-models/tree/master/mobilenet)의 ImageNet 분류를 사용합니다. 인식 범위 밖이거나 점수가 낮으면 품목을 단정하지 않고 직접 선택하도록 안내합니다. 재질은 사진만으로 확정하지 않으며 사용자가 확인합니다.
- 배출일은 [전국생활쓰레기배출정보표준데이터](https://www.data.go.kr/data/15025450/standard.do)를 정리한 [광산구 공개 자료](https://trashpedia.kr/gwangju/gwangsan-gu)의 2023-05-31 기준 일정입니다. 실제 운영 일정은 공휴일, 공동주택, 세부 노선에 따라 달라질 수 있습니다. 최신 공단 자료가 연결되기 전에는 참고용으로만 사용하세요.
- 판매소는 [전국종량제봉투판매소표준데이터](https://www.data.go.kr/data/15114144/standard.do)에서 공개된 2024-09-05 기준 목록 중 7곳입니다. 전체 판매소 목록이나 실시간 영업·재고 정보는 포함되지 않습니다. 봉투 종류는 확인 가능한 데이터가 없어 표시하지 않습니다.
- 위치 계산은 [Nominatim](https://operations.osmfoundation.org/policies/nominatim/)을 사용해 브라우저에서 요청합니다. 캐시와 요청 간격을 적용했으며, 지오코딩이 실패하면 주소와 지도 링크를 제공합니다. 지도·길찾기는 Google Maps를 엽니다.

## 로컬 실행

`dist/` 폴더를 정적 파일 서버로 제공하면 됩니다. 사진 분석은 처음 사용할 때 모델 파일을 내려받으므로 인터넷 연결이 필요합니다. 카메라와 위치 권한은 HTTPS 또는 localhost에서 동작합니다.

## 운영 전 필요한 연결

광산구시설관리공단의 최신 동별 수거 노선과 전체 봉투 판매소 데이터가 제공되면 `dist/app.js`의 `regionGroups`와 `stores`를 갱신하세요. 운영 데이터 연결 전 화면의 기준일·참고 안내를 유지해야 합니다.
